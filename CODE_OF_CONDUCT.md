# Code of Conduct

## Our Pledge

We are committed to making this project a welcoming, respectful, and harassment-free environment for everyone.

## Expected Behavior

- Be respectful and considerate.
- Communicate constructively.
- Respect different opinions and experiences.
- Help maintain a friendly and inclusive community.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, threats, or inappropriate conduct will not be tolerated.

## Reporting

If you experience or witness unacceptable behavior, please report it to the project maintainer through the contact information provided in this repository.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this Code of Conduct.

## Scope

This Code of Conduct applies to the project's repository, discussions, issues, pull requests, and other project-related interactions.

## Attribution

This Code of Conduct is inspired by the Contributor Covenant.
